# 机场客户端配置指南

> 新手向，手把手教你从注册到用上，全程约 5 分钟。

---

## 第一步：选择并注册机场

如果你还没选好，参考我们的 [机场推荐](../README.md#-热门推荐) 挑一个。

推荐新手入门选 **自由猫**（¥6/月起，性价比最高）→ [立即注册](https://tochick.xyz/10)

注册完成后，一般会进入用户后台面板。

---

## 第二步：获取订阅链接

登录机场的用户中心，找到 **「订阅」** 或 **「我的订阅」** 页面：

1. 点击 **「复制订阅链接」**（通常是一个以 `https://` 开头的长链接）
2. 部分机场提供 **「一键导入」** 按钮，可以直接跳转到客户端

> 💡 订阅链接是你的专属凭证，**不要分享给他人**，否则可能被滥用封号。

---

## 第三步：下载客户端

按你的设备选择客户端：

| 平台 | 推荐客户端 | 下载方式 |
|:----|:----------|:--------|
| **Windows** | Clash Meta (CFW) / v2rayN | 官网或 GitHub Releases |
| **macOS** | ClashX / Stash（付费） | 官网下载 |
| **Android** | Clash Meta for Android / Surfboard | Google Play 或官网 |
| **iOS** | Stash（推荐）/ Shadowrocket | App Store（部分需美区账号） |
| **Linux** | Clash Verge | GitHub Releases |
| **路由器** | OpenClash / PassWall | 路由器插件市场 |

> ⚠️ iOS 推荐使用 **Stash**（付费），部分机场可能不支持 Shadowrocket。

---

## 第四步：配置客户端

### Windows/macOS (Clash Meta)

1. 打开 Clash Meta
2. 点击 **「订阅」** → **「添加」**
3. 填入以下信息：
   - **名称**：随意，比如"我的机场"
   - **订阅链接**：粘贴第二步复制的链接
4. 点击 **「导入」**
5. 切换到 **「代理」** 面板，选择一个节点
6. 开启 **「系统代理」** 或 **「TUN 模式」**（推荐 TUN 模式）

### Android (Clash Meta for Android)

1. 打开 App
2. 点击配置文件旁的 **「+」** → **「从 URL 导入」**
3. 粘贴订阅链接 → 点击 **「确定」**
4. 点击配置文件名称启用
5. 点击 **「启动」** 按钮

### iOS (Stash)

1. 打开 Stash
2. 点击 **「+」** → **「从 URL 下载」**
3. 粘贴订阅链接
4. 启用配置后点击 **「连接」**

## 第五步：验证是否成功

打开浏览器访问以下网站验证：

| 检测项 | 网站 | 说明 |
|:-----|:----|:----|
| IP 检测 | https://ip.sb | 看 IP 是否变为海外地址 |
| 流媒体解锁 | https://fast.com | 测速并验证 |
| Google | https://google.com | 能否正常访问 |
| YouTube | https://youtube.com | 能否播放 4K 视频 |
| ChatGPT | https://chatgpt.com | 能否打开（部分机场支持） |

## 常见问题

### ❓ 连不上怎么办？

1. 检查订阅是否过期
2. 切换其他节点试试
3. 更新订阅（点击「更新」按钮重新拉取）
4. 尝试关闭防火墙/杀毒软件
5. 更换协议模式（切换到 TUN 模式）

### ❓ 速度慢怎么办？

1. 切换到离你物理位置更近的节点
2. 避开晚高峰（部分线路晚高峰会限速）
3. 换其他机场试试 → [机场对比](../airports/README.md)

### ❓ 提示「订阅失效」

1. 回到机场后台重新复制订阅链接
2. 在客户端重新导入
